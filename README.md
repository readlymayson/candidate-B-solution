# Отчёт по оплатам работ и договоров

Небольшая CLI-программа на Python 3.10+. Использует только стандартную библиотеку.

## Запуск

Из корня проекта:

```bash
python src/report.py --data data --as-of 2026-11-10 --out out
```

Результат:
- `out/works_report.csv` — стоимость, прямые платежи, распределённые авансы, оплачено и остаток по каждой работе;
- `out/contracts_report.csv` — итоги по каждому договору, включая платежи в очереди и нераспределённую часть оплаты. В нём отдельно показаны общая стоимость работ, стоимость отменённых работ и стоимость активных работ на отчётную дату.

CSV записывается в UTF-8 с BOM, чтобы корректно открываться в Excel.

## Проверка

```bash
python -m unittest discover -s tests -v
```

## Входные данные

В `data/` должны находиться `contracts.csv`, `works.csv` и `payments.csv` в формате из исходного задания. Дата отчёта задаётся параметром `--as-of`.

## Важное ограничение

Это расчётный отчёт на основе выгрузки, а не бухгалтерская проводка. Правила распределения авансов описаны в `DECISIONS.md`; их нужно подтвердить у бухгалтера.
